# 画说 · 把 AI 的回答拆成一墙可画可改的卡片

一个纯前端的"AI 学习笔记画布"：把题目或文档丢进去，AI 的回答会被拆成一张张卡片摆在无限画布上，
可以连线、框选追问、划线圈重点、画函数图，也能直接导出成一整张图。

> 在线使用：**https://kaqka5.github.io/huashuo/**

## 是什么

- 首页一个问题，回车 → 画布上自动长出一串卡片（步骤、引文、结论、英文对照…）
- 七个工具：移动 / 划线 / 画圈 / 方框 / 提问 / 截取 / 分框 / 函数图，快捷键都能自己改
- 框住一句话就能追问，AI 的回答作为「追问板块」贴在旁边，用虚线指着原句
- 卡片可以拖动、合并（上下左右都行）、拆分、改编号
- 函数图：框住式子就自动画出二维图像或三维曲面
- 导出 PNG，或者导出项目文件换台电脑接着画

## 技术

纯静态：原生 JS + CSS，没有构建步骤、没有第三方库、不联网也能开（AI 功能除外）。
LaTeX 排版、PDF 文字提取、SVG 导图都是自己实现的。

## 本地打开

双击 `index.html` 即可（或 `node server.js` 起个本地服务）。

## 数据

所有内容存在浏览器的 localStorage 里，不会上传。AI 的 API Key 也只存在本机。
